# JellyCrowd

Jellyfin plugin repository. The plugin lives under [`JellyCrowd/`](JellyCrowd/) and the
Jellyfin plugin-repository manifest is [`manifest.json`](manifest.json) at the root.

Add this repository in Jellyfin → Dashboard → Plugins → Repositories:

```
https://raw.githubusercontent.com/LokLakh-s/JellyCrowd/main/manifest.json
```
